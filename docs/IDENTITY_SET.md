# Proposed preservation identity set

Status: proposed; user selection pending. This is the bounded G0 product decision
required by the approved plan, not a claim about recovered historical modes.

| Mode | Evidence | Proposed acceptance |
| --- | --- | --- |
| Classic artwork player | Observed layout; new assets | Dark blue background, title/artist header, original artwork placeholder, circular play/pause, progress, queue, paging; measured reference comparison |
| Full-page synchronized lyrics | Page structure observed; timing behavior reconstructed | Active line centered, surrounding dimmed lines, accurate seek/pause following, import and signed delay control; known-cue test |
| Spectrum stage, portrait/landscape | Reconstruction; original animation unavailable | Ten audio-reactive frequency bands on the dark classic background, controls remain available, silence/tones/pause tests; no microphone |

Recommendation: use these three presentations as the initial required 1.0 set.
Artwork and lyrics are needed in alpha regardless. The spectrum stage is the
beta visualizer. An optional oscilloscope stage would draw the actual waveform
with the same controls, but adds implementation and fidelity review work.

Do not call this an exact inventory of original TTPod visualizers. Additional
remembered modes can be added to the explicit set before M4 rather than silently
substituting an arbitrary equalizer animation for preservation.
