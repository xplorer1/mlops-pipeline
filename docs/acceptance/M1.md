# M0/M1 implementation evidence

Date: 2026-09-27. Status: development foundation; gates remain open.
The approved implementation plan is unchanged. This record describes actual
checks, not completion of the full preservation product.

## Build and test evidence

- Seven domain JUnit tests passed, zero failures/errors: LRC offsets, encoding,
  malformed input, bounds, and queue-rule helpers.
- Debug app and both instrumentation APKs built successfully.
- API 23 / Android 6 x86_64: three app integration tests passed. Generated WAV
  scanned through MediaStore; playback advanced after the Activity finished;
  queue checkpoint saved. Valid lyric import and preservation after invalid
  replacement passed. Manifest checked for absence of INTERNET permission.
- API 23: two PCM tests passed. Samples survive processing/flush and rate
  changes without alteration; empty input is safely drained.
- Tests exposed and fixed an empty-buffer aliasing bug in the PCM probe.
  Earlier failing logs are retained privately, not counted as passing evidence.
- Direct ADB instrumentation avoids the modern Gradle collector misinterpreting
  API 23's unsupported `am get-current-user` command.
- Final lint and optimized unsigned release build passed (146 executed tasks).
  Lint reports zero errors and 65 warnings; these remain cleanup work, not a
  zero-warning quality claim.
- API 37 is blocked before app installation: the system's SurfaceFlinger aborts
  with `Assertion failed: !rcEnc->featureInfo()->hasReadColorBufferDma` and restarts
  framework services. Reproduced with emulator 35.6.11, stable 37.1.11 and preview
  37.3.1. Disabling GLDMA or the direct/shared memory flags did not resolve it.
  Enlarging the dev AVD from 800 MB to 4 GB resolved an independent no-space
  install error. No modern-API success is claimed. The original lab is intact.

`reference-private/adb-pcm-api23.log` (2 tests),
`reference-private/build-fix.log`. Domain XML is under

Release/lint log: `reference-private/lint-release.log`. The unsigned release APK

## Final device demonstration

The final rebuild (`reference-private/build-final.log`) passed domain tests,
debug/test APKs, optimized release and lint. The final direct-device run
(`reference-private/tests-api23-final.log`) passed all three app tests and both
PCM tests. The app test now also exercises scan-button toast feedback.

The actual API 23 system picker selected Internal storage > Download >
TwinkleDemo.lrc. Import completed and highlighted lyrics followed the generated
song. A manual check caught an API 23 Toast/AppCompat inflation crash, fixed by
using application context for the Toast; reimport on the final build succeeded.
The paused screen no longer needlessly refreshes every 100 ms.

Screenshot: `reference-private/screenshots/newapp-lyrics-playing.png`.

bytes, one queue item, playing=true and position 27730 ms. After force-stop and
relaunch, `reference-private/recovery-live.txt` reports one queue item restored
paused at checkpoint 23457 ms. Lyric selection persisted; explicit Play resumed.
The demo is left on the lyric page with repeat-one enabled.

Final debug APK: `app/build/outputs/apk/debug/app-debug.apk`, version
`0.1.0-dev`, application ID `org.ttpod.recreation.dev`.

## Limits and remaining gates

- G0: [identity proposal](../IDENTITY_SET.md) awaits user selection; reference
  queue measurements remain incomplete.
- G1: current-platform verification is blocked by the emulator crash; remaining
  risk probes/model review are open. Parser success does not close SAF/audio gates.
- Automated lyric import uses a test-owned URI. Manual system-picker import is
  now verified on API 23, but modern grants, revocation and sidecar trees remain.
- Background playback was a short Activity-closed test, not 60-minute
  screen-off, Bluetooth, calls or physical audio quality verification.
- Single-track process recovery is verified; interruptions, multi-track shuffle
  recovery and queue mutations need broader tests. Only selection/clear exposed.
- Scan upserts source locators. Missing-file states, relinking and stable
  identity through moves remain model work before playlists depend on it.
- G2 alpha: fidelity, landscape, lyric scrolling/seek, artwork/format fixtures,
  permissions, large libraries, accessibility and physical listening remain.
- M3–M7 are not implemented. No skins, EQ, visualizer, online provider, overlay,
  widget, export, production signing or upgrade certification is claimed.
